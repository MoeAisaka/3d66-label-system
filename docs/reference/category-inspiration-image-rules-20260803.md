文档标题：【灵感图】-prompt（深圳特鹏网络有限公司 · 林周金）

> 本文件是重构讨论的需求原文快照，仅作为设计输入，不是最终配置。以实际钉钉文档为准。

## 核心目标
对上传图片进行全维度专业评估，给出 1-100 分整数综合评分，用途为高端设计师素材网站首页推荐图准入筛选。
- 精准红线否决：识别所有不合格素材，直接过滤
- 严控高分含金量
- 精准定级分层
- 核心底线：80 分以上高分段实行零硬伤准入

## 评审全流程刚性执行顺序

### 一、红线检测（前置过滤）
最先扫描全图，匹配以下四类红线，任意命中直接锁定总分 ≤49，终止后续所有打分流程（映射为等级 L5，不再进入评测）：
1. 截图：画面包含手机/电脑界面、状态栏、窗口控件
2. 随手拍：无规范一点/两点/三点透视，透视杂乱无章法
3. 大面积文字：文字、标注占画面总面积 ≥40%；豁免：轻量化效果图辅助文字、专业海报
4. 大面积二维码：二维码区域占画面 ≥50%；豁免：角落极小尺寸二维码

### 二、赛道分类（节点二）
无触发红线的素材，先判定媒介类型再判定图片赛道，分三类：
1. 一类：建筑 / 室内 / 景观 / 规划
2. 二类：产品家具 / 雕塑 / 装置 / 美术 / 游戏原画
3. 三类：其他无关图片（人像、纯风景、抽象画、杂物静物等其他媒介杂图）

### 三、分数计算顺序
1. 初始基底分 = 对应赛道基准分（一、三类 40 分；二类 20 分）+ 维度满分（六维 60 / 五维 30）
   - 一类 = 100（40+60）、二类 = 80（20+60）、三类 = 70（40+30）
2. 依次扣减：维度扣分、媒介类型固定扣分
3. 最后执行硬性封顶（赛道上限、80 分以上一票压分铁律）

### 四、6 大核心维度（一类、二类专用，满分 60）
1. 视觉结构 10：构图失衡、主体裁切扣 3~5；重度同质化再扣 5
2. 色彩美学 10：色调违和、偏色、饱和度失衡扣 3~5
3. 情感表达 5：氛围平淡空洞、无叙事感扣 3
4. 设计美学 10：空间压抑、尺度比例失真扣 3~5；重度同质化再扣 5
5. 原创设计感 10：重度同质化扣 8；小幅改良、无颠覆创新扣 4
6. 设计流行度 15：老旧网红制式、审美过时扣 7

### 五、5 大简易维度（仅三类专用，满分 30，单维度满分 6）
1. 主题清晰焦点：主体模糊、裁切丢失核心内容扣 3
2. 情绪氛围可感知：光影色彩杂乱、氛围平淡扣 3
3. 构图光影专业章法：构图无序、光影断层矛盾扣 3
4. 内容借鉴价值：通用烂大街场景扣 3
5. 强视觉冲击力：画面平淡、无记忆点扣 3

### 六、媒介类型固定扣分（固定通用维度）
1. 媒介分类：
   - 实景照片：项目落地实拍影像
   - 3D 数字效果图：SU/D5/Enscape 等专业渲染，结构完整
   - AI 图：批量网红家装、比例崩坏、全网同款模板
   - 其它：无法判定时强制「其它」
2. 同等画面质量下以实拍为基准：效果图扣 5，AI 图在效果图基础再扣 10（相对实拍共扣 15）

### 七、80 分以上一票压分铁律（最终校验）
满足任意一条，总分强制 ≤79，无豁免：
1. 画面模糊发灰、分辨率低、压缩痕迹、噪点、材质廉价
2. 构图敷衍、元素堆砌、无设计逻辑、比例失调
3. 色彩艳俗、饱和度过高、灯光刺眼、光影假白失真
4. 大面积死黑、暗部缺细节、明暗断层、光影矛盾
5. 视角怪异、透视畸形、主体严重裁切
6. 材质虚假、反光失真、纹理模糊、细节缺失
7. 鱼眼/超广角严重畸变，垂直线条倾斜、边缘扭曲
8. 大面积无效黑边、生硬裁切线，主体被遮挡
9. 整体严重偏色，光影违和，违背真实材质质感
10. 知名落地实拍建筑素材出现以上硬伤同样无豁免，直接压至 79

## 智能标签与命名执行指令
判定逻辑：
1. 优先识别核心材质/属性，确定一级分类
   - 一级分类仅允许：建筑设计，景观设计，规划设计，居住空间，酒店民宿，办公空间，商业空间，公共空间，展示设计，软装设计，硬装结构，意向图，视觉设计，产品设计，美术类，游戏设计，其它
2. 一级分类确定后，生成专业的二级分类词
3. 一级分类无法确定时强制「其它」

## 待澄清点（讨论用）
- 红线命中 → 总分≤49 与「直接产出 L5」的映射：score≤49 是否恒等 L5，还是 L5 仅红线命中专用？
- 调用 A / 调用 B / 维度三者的功能边界需固化（见讨论稿）。
- 赛道分类（track）与「一级分类」标签是两套体系还是同一套？当前文档中 track 用于计分基底，一级分类用于标签命名。
