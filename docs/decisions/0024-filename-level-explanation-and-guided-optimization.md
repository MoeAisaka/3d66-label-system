# ADR-0024：文件名建议等级、可解释回归与连续优化工作流

- 状态：Accepted
- 日期：2026-07-31

## 背景

基准回归需要快速复用已有等级素材，但当前需求已取消 Excel 图片 URL 获取。
等级信息改为包含在上传图片名称中。文件名可能缺少等级、包含多个冲突等级，
也可能被操作员重新判断，因此它只能提供默认值，不能成为不可修改的真值。

回归结果此前只显示等级和分数，缺少服务端判级理由；人工确认、纠偏和退回又
需要跳转到独立审核页。纠偏案例进入队列后，页面只显示“待组批”，没有告诉
操作员如何形成批次、试跑、生成候选或验证候选，安全策略参数也直接暴露为
运维术语，导致业务流程割裂。

## 决策

### 1. 文件名等级只做可编辑建议

上传图片名称按独立 token 识别以下等级：

- `L1`、`l1`、`好` → `L1`
- `L2`、`l2`、`中等` → `L2`
- `L3`、`l3`、`中差` → `L3`
- `L4`、`l4`、`极差` → `L4`
- `L5`、`l5`、`过滤` → `L5`

无匹配时使用整批默认值；同一文件名命中多个不同等级时视为冲突，不猜测，
同样回退整批默认值。操作员可在创建基准集前逐张修改。创建后冻结最终
`expected_level`，并记录来源为 `filename`、`batch_default` 或
`manual_override`。

当前需求不实现 Excel 解析、内网图片 URL 拉取或远端原图冻结。既有安全离线
导入基础设施继续保留，但不接入本次素材主流程。

### 2. 回归结果冻结结构化判级理由

新完成的回归结果使用 `baseline-result-v2` 快照，并从本次评测已保存的
`aesthetic_json` 与 `scoring_json` 生成 `level_explanation`，不增加模型调用。
理由至少包含最终等级、服务端分数、主要优势/短板维度、视觉证据与缺陷、
等级限制、人工复核原因，以及超范围或结果不完整原因。

历史结果没有冻结该字段时，接口和页面必须明确显示“历史结果未冻结评测理由”，
不得根据当前规则补算并伪装成历史事实。

### 3. 基准回归原位复用正式审核事实源

基准回归逐张结果可直接确认、退回或展开逐维纠偏，提交继续复用
`EvaluationResult`、`ReviewPanel`、`HumanReview` 和统一审核并发门禁。
页面展示待审核、审核中、已确认、已纠偏、已退回及人工最终等级。

人工结论不得覆盖模型原始预测，也不得修改不可变基准集中的冻结期望等级。
回归指标始终比较原始预测与冻结期望等级；人工结论只作为独立审核事实展示。

### 4. 优化流程按业务任务连续呈现

优化入口统一呈现三步：

1. 收集案例：人工纠偏、基准偏差和生产回流进入只追加案例池。
2. 组批与生成：同一提示词版本组批，先生成安全试跑计划，再按需真实执行。
3. 验证候选：查看候选提示词，通过配对回归和人工发布门决定是否发布。

案例池必须展示状态汇总和当前下一步；“自动优化编排”改为“案例组批与优化”。
首次使用提供“一键生成安全试跑计划”：启用消费者、保持 `dry_run=true`，
并按当前同版本可用案例形成批次。该动作只冻结案例范围，不调用模型、不计费、
不发布。

配置项使用业务语言解释用途。P0～P3 选择表示哪些严重度无需等满组批门槛即可
触发；租约、退避和重试折叠为高级恢复设置。真实执行仍要求模型配置、正数
预算和显式风险确认，结果最多生成候选草稿和配对回归，永久禁止自动发布。

## 后果

- 批量创建基准集更快，但文件名仍是可审查建议，不会把命名错误固化为真值。
- 回归等级可直接追溯到冻结证据，历史缺失也不会被当前规则污染。
- 操作员从“待组批”可以沿明确下一步完成试跑、真实生成和候选验证。
- 安全试跑会把策略保持在只试运行状态；若要真实执行，必须重新核对组批门槛、
模型、预算和风险确认。
- 当前不承担 Excel 与内网图片下载的安全、网络和失败原子性复杂度。

## 不可破坏约束

- 文件名解析不得写死为不可修改等级，不得在冲突时猜测。
- 基准集创建后仍不可变；人工审核不得覆盖模型预测或冻结期望等级。
- 历史理由缺失必须显式标记，不得事后伪造。
- 安全试跑不得调用模型、产生费用或发布提示词。
- 自动优化不得绕过预算、执行器配置、配对回归和人工发布门。
- 不得因取消 Excel 需求而把普通 HTTP 下载接入素材上传链路。
