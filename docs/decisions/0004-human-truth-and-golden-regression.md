# ADR-0004：人工真值与黄金样本回归

- 状态：Accepted
- 日期：2026-07-19

## 背景

旧模型、豆包新模型和 ChatGPT/SOL 都可能给出不同答案。把任一模型天然视为正确，会把已有偏差固化到提示词和迁移判断中。

## 决策

- 黄金真值必须经过人工确认。
- 真值可以包含最终等级、分类、形态、画质、八维分数、原因和证据。
- 黄金样本集锁定后用于提示词和模型的全量回归。
- 真值修改必须产生修订历史，记录审核人、原因和时间。
- 模型升级时优先对比人工真值；旧模型历史结果只作为基线和回退线索。
- AI 可以诊断纠错模式并提出候选提示词，但不能自动修改黄金真值或直接发布。

## 后果

- 人工审核必须记录“哪个维度错、为什么错”，不能只改最终等级。
- 黄金集要覆盖等级、素材类型、画质问题和高风险边界，不能只选典型好图。
- 发布流程最终应在回归达标前阻止上线；当前“发布后自动创建回归”仍需改造。

## 不可破坏约束

任何模型答案都不能未经人工确认直接成为黄金真值。
