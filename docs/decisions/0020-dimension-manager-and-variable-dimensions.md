# ADR-0020：维度管理器与可变维度评审

- 状态：Accepted
- 日期：2026-07-31

## 背景

现役空间评审依赖一套固定八维。维度、锚点、权重、等级换算和标签字段散落在
评分、复核、抽样、回归、优化器和前端中。素材不适合空间八维时，旧链路容易
把“规则不匹配”误当成“素材不可评”，既不能稳定产出结果，也不能实验更合适的
评审规则。

实验台的目标不是把某一套维度永久写死，而是把维度规则提升为与提示词同等的
版本化实验对象，逐步选出最优的“维度规则 × 提示词 × 标签字段”组合。同时，
不同版本的历史结果必须可解释、可回放，不能因维度变化失去审计语义。

## 决策

### 1. DimensionSchema 是一等版本化实体

- 每个维度包保存稳定业务键、版本、素材族、状态、完整定义、规范哈希、父包、
  L0 核心包、候选来源和发布审计。
- 定义包含维度键、中文标签、锚点、权重、等级换算、L1～L5 阈值、聚合规则、
  标签字段和必要的 Engine/risk-review 合同。
- 已发布或已停用版本不可原地修改或删除；任何变化创建新版本。
- 评测结果、人工真值和回归证据必须冻结完整 Schema 身份与定义。不同 Schema
  默认不可比较，只有显式、版本化映射才允许跨规则比较。

### 2. 固定核心与可变扩展分层

- L0 固定核心维使用：
  `presentation_integrity`、`visual_hierarchy`、
  `inspiration_reference`。
- 固定维采用结构化、服务端确定执行的 skill/workflow 形态，提供全库可比锚点。
- 扩展维采用可版本化、可校准、可回归、可发布和可回滚的提示词式实验形态。
- 首批素材族为：空间、单品、平面、意向。
- 现役八维零损平移为兼容空间包；首个扩展候选为单品包。

### 3. 维度路由策略必须版本化和冻结

- `DimensionRoutePolicy` 保存分类/信号到素材族、DimensionSchema 和 B 阶段
  合同的确定性映射，并使用规范 JSON 与 SHA-256 标识。
- 评测入队最终必须冻结 A 提示词、路由策略和全部候选 Schema/B/标签合同；
  A 返回后只允许从冻结候选中解析，禁止读取“当前最新版本”。
- `out_of_scope` 不再等于“不出结果”。规则不适配时路由到对应素材族；未知、
  冲突或低置信输入回落 L0，并标记人工复核。
- 只有受控的真正不可评原因才允许不评分。当前受控原因至少包括
  `quality_severity=unusable`。

### 4. 新维度包先校准，后进入生产候选

- 每个新包至少完成 50 张、目标 100 张人工校准集。
- 校准集必须包含目标错例、稳定对照和盲测留出三类证据。
- 维度包、B 提示词和标签字段作为一个 Evaluation Profile 共同回归、共同审批。
- 未满足校准门、缺少 B 提示词合同或缺少冻结证据的候选不得进入生产 Worker。
- P2-S1 只交付只读候选注册表、确定性解析器和管理界面；候选策略固定为
  `calibration_only`，生产上下文调用必须 fail-closed。

### 5. 分期落地

1. P1：DimensionSchema、空间包平移、各消费者 Schema 化和前端动态显示，
   以冻结空间样本零漂移为门禁。
2. P2-S1：L0、单品候选包、版本化路由策略、确定性解析器和只读管理界面；
   不接生产 Worker。
3. P2-S2：重构入队冻结时序，接入 A 后解析与 Evaluation Profile 冻结；
   通过重放与并发门禁后才允许受控试点。
4. P3：维度候选枚举器、校准集和配对回归。
5. P4：维度规则、提示词和标签字段的三元组横评选优。

## 后果

- 不符合空间八维的素材可以得到适合其素材族的多维结果，而不是落入无结果黑洞。
- 固定核心维保留跨素材族的最小可比性；扩展维提供适配性和实验空间。
- 路由和 Schema 都进入冻结合同，回放、回滚和审计成本增加，但避免历史结果
  被“最新规则”重新解释。
- 单品、平面和意向包在达到校准门前只能作为候选查看，不会误入生产。

## 不可破坏约束

1. 未知素材族不得静默无结果；默认回落 L0 并进入人工复核。
2. 生产解析不得读取未冻结的最新路由、Schema、Prompt 或标签合同。
3. 候选路由策略、校准未完成的维度包和缺少 B 合同的 Profile 不得进入生产。
4. 现役空间包在 P1/P2 重构中的分数、等级、维度明细、封顶和复核原因必须零漂移。
5. 媒介和画质硬封顶独立于维度包，仍只能降级、不能抬高最终等级。
6. 已发布的 Schema、RoutePolicy、结果快照、真值和回归证据不可原地改写或删除。
7. 维度路由失败必须返回稳定错误码或受控回落，禁止用异常吞掉评测结果。
8. 不引入第二套密钥、模型配置或提示词发布体系。
