# ADR-0006：风险优先、稳定可解释的审核抽样

- 状态：Accepted
- 日期：2026-07-19

## 背景

全量人工审核成本过高，但简单随机抽样会漏掉黄金样本、模型冷启动、低置信度、结果异常和版本回退。每次刷新重新随机也会让审核队列无法复现。

## 决策

- 审核队列分为必须审核、抽样审核、暂缓审核和已审核。
- 黄金样本、人工退回、低置信度、高等级、严重/不确定画质、自动复核异常、跨版本大幅变化、冷启动、八维缺失或完全同分进入必须审核。
- 中置信度、中度画质、边界判断和轻微版本变化进入抽样审核。
- 其余常规结果使用结果 ID、模型和 A/B 版本生成稳定哈希，按固定比例抽样。
- 每条决策返回规则/策略版本、优先级和人类可读原因。
- 已人工确认或纠正的结果进入已审核状态；人工退回继续必审。
- 抽样比例和关键阈值允许配置并产生策略修订号。

## 后果

- 同一结果在相同策略下刷新不会改变是否被抽中。
- 不能只展示分数，必须告诉审核员为什么进入队列。
- 当前实现仍扫描全部历史结果；后续应按活跃组合/任务批次组织待办，并持久化当时的策略快照。

## 不可破坏约束

降低抽样率不得绕过黄金样本、明确异常、冷启动或人工退回等必须审核规则。
