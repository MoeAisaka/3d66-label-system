# ADR-0005：本地优先数据与密钥安全

- 状态：Accepted
- 日期：2026-07-19

## 背景

当前阶段是 Windows 局域网 Demo，每天不超过 1000 张，暂不接素材库、对象存储或企业权限系统。API Key 和图片不应进入代码仓库。

## 决策

- 服务运行在 Windows 主机，局域网审核员通过浏览器访问。
- 数据默认保存到 `%LOCALAPPDATA%\3d66-label-system`，包括 SQLite、图片和日志。
- API Key 使用当前 Windows 用户的 DPAPI 加密，前端不回显完整密钥。
- Git 只保存代码、提示词、配置结构、文档和测试。
- `.env`、数据库、图片、日志、虚拟环境、依赖目录和构建产物不进 Git。
- Demo 换电脑时允许重新配置和重跑；正式阶段再增加不含密钥的备份/恢复包。

## 后果

- 代码可通过私有 Git 跨电脑同步，但运行数据不会自动跟随。
- 数据库复制到新电脑后，原 API Key 不能解密，必须重新填写。
- 主机关闭后局域网用户无法访问。

## 不可破坏约束

不得为了方便迁移而把真实 API Key、明文密码、数据库或原始图片提交到 Git。
