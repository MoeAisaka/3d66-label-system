# ADR-0031：类目维度管理与仅提示词评测模式

- 状态：Accepted
- 日期：2026-08-02

## 背景

维度管理器此前只能读取已经物化的维度 Schema，管理员不能按类目增减维度，也不能
暂时关闭维度评测。这使实验台无法比较“提示词直接结论”与“提示词加维度评分”的质量
差异，也容易诱导管理员直接改写已发布规则，破坏历史任务解释能力。

## 决策

1. 已发布和已停用的维度 Schema 继续不可变。增加、删除、重排或修改维度时，必须
   创建新的草稿/候选版本，不能覆盖历史版本。
2. 类目流水线保存独立的维度执行配置：
   - `enabled=true, mode=all`：执行绑定 Schema 的全部维度；
   - `enabled=true, mode=selected`：只执行管理员选择的维度；
   - `enabled=false`：关闭维度评测，进入仅提示词模式。
3. 仅提示词模式仍保留提示词、模型、类目、处理链和服务端结果快照；维度 Schema
   身份可作为配置来源记录，但不要求生成维度分数、维度纠偏或维度聚合结果。
4. 任务入队时冻结完整类目配置、维度开关、启用维度键和 Schema 定义。管理员后续
   修改类目或维度版本，不影响已排队任务、历史结果、黄金集和回归证据。
5. 维度配置按类目隔离。一个类目的维度增删、选择或关闭，不得改变其他类目的流水线。
6. 二审评测包必须明确显示维度评测状态；关闭时显示“仅提示词评测”，启用时显示
   实际冻结的维度列表和版本，不能用当前配置替代历史快照。

## 后果

- 管理员可以建立多套类目维度方案并进行全维、部分维度和零维度实验。
- 发布维度版本的操作成本增加，但换来历史结果可解释、回归可复现和并发修改安全。
- 仅提示词模式的结果不能进入依赖维度人工真值的自动评分/纠偏链路；相关页面必须按
  冻结模式降级展示，不得把缺少维度误报为合同损坏。

## 不可破坏约束

- 禁止原地编辑或删除已发布/已停用 Schema。
- 禁止类目引用不存在、未获准状态或结构无效的维度版本。
- `selected` 模式必须至少选择一个属于绑定 Schema 的维度；`enabled=false` 时不允许
  残留生效的维度键。
- 禁止用类目当前配置回填历史任务；所有执行、二审和回归判断以冻结快照为准。
