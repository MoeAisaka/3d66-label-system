# ADR-0036：灵感图美感基础事实前置固化，规则层只读定级

- 状态：Accepted
- 日期：2026-08-06
- 适用类目：`inspiration_image`

## 背景

旧 rev4 调用 A 是红线、赛道、媒介与硬伤的事实前检，不输出八维或美感分；旧调用
B 直接输出最终分数与等级。因此系统不存在“稳定美感事实先产生，再由 v3 运营规则
从严扣分”的可审计分层，规则效果与模型美感判断无法分别归因。

阶段 1c 的四锚图 D 变体在修正人工标签后是唯一覆盖 L1–L4 且保持完整单调的方案。
运营口径已冻结为“美感从宽，v3 合同按赛道从严；两可往下打；L5 过滤”。

## 决策

1. 调用 A 继续使用 rev4 原合同，不改提示词、schema 或职责。红线在 A 后短路，直接
   输出 L5，禁止调用 B。
2. 非红线样本进入新调用 B `inspiration-b-v3-anchor-aesthetic-20260806`。输入顺序固定
   为四张 Owner 锚图（2045/L1、747/L2、1263/L3、601/L4）和一张待评图；锚图文件
   在调用前逐个核对 SHA-256。
3. 调用 B 只输出严格 JSON：连续整数 `aesthetic_score`、冻结八维的 1–5 grade、逐维
   可见证据、总体证据与置信度；不得输出最终等级、最终分数、标签或发布字段。缺失、
   多余字段、0 值、null、锚图缺失或 hash 不符均 fail-closed，且不自动重试。
4. 经严格校验的完整调用 B 结果先 canonicalize，并在独立事务中写入
   `EvaluationJob.inspiration_aesthetic_*`。冻结时间存在后，SQLite 触发器禁止更新美感分、
   JSON、hash 或冻结时间。
5. v3 引擎只读冻结值。规则前后重新 canonicalize 并逐值比较；任何分层污染均硬失败。
   `EvaluationResult.inspiration_aesthetic_score` 与结果 API保留该前置值，不能被最终分覆盖。
6. 初始美感分映射是合同可配参数：L1 90–100、L2 75–89、L3 60–74、L4 0–59；这是
   临时值，必须用黄金样本另行校准。整数阈值按下档边界解释，禁止模糊四舍五入上档。
7. 美感档进入既有 v3 赛道 cap、媒介惩罚开关、硬伤严重度、红线与封顶规则，最终由
   服务端确定性映射 L1–L5。调用 B 永远不拥有最终等级权威。
8. 新行为以独立灵感图 revision 激活。旧 rev4 revision 与旧调用 B 均保留，回滚只需
   重新激活旧 revision/重新绑定旧 prompt B，不删除历史记录。

## 后果

- 同一张图的美感基础与运营规则压档可以分别回放、比较和归因。
- 规则调优不能“污染”美感基准，后续阈值校准也无需重新解释模型输出。
- 每个非红线样本由一张图调用变为五图调用，输入 token、图像成本与延迟会上升；真实
  金丝雀必须记录成本，且以调用上限保护。
- L5 只作为过滤/淘汰档，不再由低美感分直接映射；低美感但未命中红线的最低档为 L4。
- 其他类目不得因测试夹具、clone 或通用 worker 探测误入该分支。

## 不可破坏约束

- 调用 A rev4 原文和输出 schema 不得被本 ADR 顺带修改。
- 只在合同 `category_key=inspiration_image` 且存在 `aesthetic_foundation` 块时启用新分支。
- 锚图资产 ID、等级、stored_name 与 SHA-256 必须作为版本化合同证据核对。
- 非红线样本未冻结合法美感基础前，v3 规则不得运行。
- 红线样本不得进入调用 B；非红线样本不得绕过调用 B 回退旧最终等级输出。
- v3 规则不得修改美感分、八维 grade、证据、置信度或其 canonical hash。
- 阈值变化必须产生新的 revision，并保留旧 revision 的可回放能力。
- `proposal_text_pdf` 及其他类目的合同、提示词和执行路径零改动。

## 回滚

1. 停止新任务并确认无处理中灵感图评测。
2. 将灵感图 profile 的 B prompt 重新绑定
   `inspiration-b-v2-human-calibrated-20260805`，并激活上一版 rev4 合同。
3. 保留迁移 58 的 nullable 列与冻结触发器；不删除历史结果，不回写已冻结字段。
4. 以健康检查、active revision、A/B 绑定及一张离线样本回放确认回滚完成。
