# ADR-0002：A/B 两阶段评测与服务端评分

- 状态：Accepted
- 日期：2026-07-19

## 背景

Doubao Lite 对过长综合提示词容易漏字段、机械同分和虚高。分类、画质判断与八维美感评分放在一次调用中，也让解析错误难以定位。

## 决策

- A 阶段判断范围、分类、素材形态、拍摄方式和画质。
- 只有 `in_scope` 或 `boundary` 才调用 B。
- B 阶段只输出美感维度、证据、缺陷和必要的判断信号。
- 最终总分、L1～L5 和等级限制由服务端版本化评分引擎计算。
- 高风险短复核只能保持或降低初评，不能提高结果。

## 后果

- `out_of_scope` 没有八维结果是正常状态。
- 模型提示词、解析 Schema 和服务端评分必须独立版本化。
- 调整权重、等级边界或限制时必须提升规则/引擎版本。

## 不可破坏约束

不得为了减少一次 API 调用重新合并成长而脆弱的综合提示词，也不得让模型自由决定最终总分而绕开服务端规则。
