# ADR-0001：素材与评测运行分离

- 状态：Accepted
- 日期：2026-07-19

## 背景

同一张图片需要被不同模型、不同 A/B 提示词和不同评分规则反复评测。如果把评测结果直接挂成素材的唯一状态，历史会被覆盖，也无法进行模型迁移和版本对比。

## 决策

- `Asset` 只保存图片自身元数据。
- 每次执行创建独立 `EvaluationJob`，完成后产生独立 `EvaluationResult`。
- `Asset 1:N EvaluationResult`，结果永不因新运行而覆盖。
- 素材 API 和页面不混入某次评测结论。
- 评测结果列表按运行展示；审核详情以 `evaluation_id` 定位。

## 后果

- 同一素材可以在结果列表出现多次，这是正确行为。
- “最新结果”只能作为显式派生视图，不能成为唯一存储。
- 筛选、审核、样本历史和迁移必须操作具体结果 ID。

## 不可破坏约束

任何新功能不得恢复成“一张素材只有一条可变评测结果”的模型。
