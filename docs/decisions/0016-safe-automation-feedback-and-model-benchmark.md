# ADR-0016：安全自动优化、不可变生产回流与三模型横评

- 状态：Accepted
- 日期：2026-07-29

## 背景

ADR-0015 已确定实验台与生产平台的双流水线，但自动优化、生产案例回流和
Sol/Terra/Luna 成本质量横评仍只有产品目标。直接接入真实模型或生产数据会把
费用、并发、重复消费、提示词误发布和生产数据污染风险带入尚未验证的链路。

## 决策

### 1. 自动优化消费者默认关闭

- 自动消费者必须由持久策略显式开启，默认 `enabled=false`、
  `dry_run=true`、日预算为零。
- 消费采用租约和条件更新 CAS，同一案例同一时刻只能被一个运行持有。
- 支持纠偏样本阈值、P0/P1 即时触发、冷却、预算、候选上限、最大尝试次数、
  指数退避和过期租约恢复。
- `dry-run` 只记录计划，不调用模型。非 `dry-run` 仍需已配置执行器和正数预算。
- 自动链路最多生成待人工发布二审的候选，任何路径都不得自动发布提示词。

### 2. 生产反馈是不可变入站事件

- 生产系统只通过版本化事件合同向实验台回传已经落地的最终人工纠偏。
- 事件以外部事件 ID 和规范化内容哈希实现幂等；相同 ID、不同内容必须冲突
  失败，不允许覆盖。
- 验证通过的事件只映射为实验台优化案例，不连接或反向写入生产数据库。
- 生产反馈事件和自动化审计事件均只追加，数据库层禁止更新和删除。

### 3. 三模型横评先冻结再执行

- 每次横评必须冻结同一 cohort、Prompt、Rubric、Engine、AgentPlan、
  StrategyBundle、模型配置与价格快照。
- 候选固定为 Sol、Terra、Luna 三个逻辑变体；测试阶段只允许
  `disabled` 或确定性 `test` 适配器，未配置真实执行器时必须明确停止。
- 指标至少覆盖质量、P0/P1、低置信度率、人工介入率、p50/p95、模型成本、
  含人工与重试的总成本和重试稳定性。
- 选择顺序是先通过质量与 P0/P1 硬门槛，再比较 Pareto 前沿与综合成本。
  横评结论只是人工生产候选建议，不得自动切换生产模型。

### 4. 所有关键动作进入只追加审计

自动组批、阈值未达、预算或冷却阻断、租约恢复、失败退避、生产反馈接收、
横评创建与测试运行均记录只追加审计事件，供系统治理工作台查询。

## 后果

- 默认配置下不会产生模型费用、候选发布或生产副作用，可以先验证状态机、
  幂等、恢复和前端信息架构。
- 真实模型执行器、生产 Outbox 发送端、自动金丝雀和生产实装需要后续独立门禁。
- 队列与实验表增加了持久状态和迁移复杂度，但换来可恢复、可审计和可重复验证。

## 不可破坏约束

1. 自动消费者默认关闭且 dry-run；不得用种子数据或迁移静默开启。
2. 任何自动路径不得发布提示词、切换生产模型或写生产数据库。
3. 生产反馈事件和审计事件不得原地修改或删除。
4. 同一优化案例不得被并发消费者重复持有；完成写入必须校验租约令牌。
5. 横评实验创建后冻结快照不得修改；测试替身结果不得冒充真实模型结果。
6. 生产候选必须先过质量/P0-P1硬门槛，并由人工最终决定。
