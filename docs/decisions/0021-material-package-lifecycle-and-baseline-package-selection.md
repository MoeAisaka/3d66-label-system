# ADR-0021：素材包生命周期与基准回归整包选择

- 状态：Accepted
- 日期：2026-07-31
- 关联：ADR-0001、ADR-0015

## 背景

实验台已经有不可变 `MaterialPackage` 与独立 `Asset`，但上传、选择和基准回归
之间仍存在四个断点：

1. 基准回归上传端在清空文件输入框后继续读取原生 `FileList`，导致请求没有
   文件，后端返回 `Field required`。
2. 素材包页与素材选择页职责重复，审核员需要在两个入口之间往返。
3. 基准集只能逐张选择，面对数百到上万条素材时不可操作。
4. 上传、文件夹、压缩包、人工整理和删除没有统一的素材包生命周期合同。

基准回归仍必须使用正常评测引擎；整包选择只是冻结真值与组织素材的操作，
不能绕开 A/B、评分、封顶或版本快照。

## 决策

### 1. 一个导入动作形成一个不可变素材包

- 一次批量图片上传形成一个素材包。
- 一次文件夹上传形成一个素材包；浏览器只上传文件，服务端不依赖客户端绝对
  路径。
- 一个 ZIP 压缩包形成一个素材包；仅接收受支持的图片，忽略目录项和常见
  元数据文件。
- 人工可从现有素材中选择一组素材，另存为新的素材包。
- 同内容素材继续按 SHA-256 复用同一 `Asset`，但每次导入来源仍新增
  `MaterialPackageItem`，以保留来源和重复记录。

素材包创建后不可修改或删除。需要重新编组时新建素材包，不覆盖旧包。

### 2. 素材删除采用可恢复的逻辑删除

- 删除操作把 `Asset.status` 置为 `deleted`，默认列表、任务创建和基准集选择
  均排除已删除素材。
- 不删除图片二进制、历史评测、人工真值、素材包条目或审计记录。
- 素材仍在排队、处理中或暂停任务内时拒绝删除。
- 再次上传相同 SHA-256 内容时恢复该素材，并继续保留原历史。

### 3. 素材选择并入素材包页

“素材与任务”只保留一个“素材包”入口。该页面同时承担：

- 批量图片、文件夹和 ZIP 上传；
- 素材包浏览与筛选；
- 从现有素材手工整理新包；
- 选择素材创建评测任务；
- 单条素材逻辑删除。

旧 `/assets` 与旧素材选择深链必须重定向到素材包页，不能保留两套可编辑入口。

### 4. 基准回归支持整包冻结

- 基准集可选择一个素材包，并给整包声明统一期望等级 L1～L5。
- 服务端按 `source_package_id` 展开包内当前有效的唯一素材；前端不得把整包
  展开限制在页面预览上限内。
- 创建时冻结展开后的素材 ID、期望等级、来源包 ID 和真值指纹；后续素材状态
  变化不改写既有基准集。
- 仍保留逐张选择与逐张指定期望等级，用于混合等级基准集。
- 偏差样本可批量加入提示词找补队列，并保留回归运行与素材来源。

### 5. 上传与压缩包安全门禁

- 普通批量/文件夹上传单次最多 1000 个文件；ZIP 最多 10000 张图片。
- 单张图片最大 25 MiB，并校验实际图片内容，不只信扩展名和 MIME。
- ZIP 拒绝绝对路径、`..` 路径穿越、加密条目、超大解压总量和异常压缩比。
- 任一导入步骤失败时回滚数据库事务，并清理本次新写入的孤立文件。

## 后果

- 审核员只需围绕素材包工作，基准回归可直接处理数百或数千条同等级素材。
- 素材包的来源记录、历史评测与真值不会因删除或重新上传丢失。
- 逻辑删除不会立即回收磁盘空间；若以后需要物理清理，必须另行设计带引用
  检查、归档与审计的维护流程。
- ZIP 解压和万条整包回归仍是有界操作；正式万条导入需继续执行分批、容量和
  性能验收，不能把上限等同于生产吞吐承诺。

## 不可破坏约束

1. `Asset 1:N EvaluationResult` 不变，素材包不得持有“唯一最新结果”。
2. 已创建素材包及其条目只读；重新编组只能创建新包。
3. 删除素材不得级联删除图片、结果、真值、包条目或审计。
4. 整包基准回归必须经过现役完整评测引擎，不得用声明等级直接伪造预测结果。
5. 基准集创建后真值与成员不可变；多轮 Run 只能新增结果。
6. 前端预览/分页上限不得截断服务端整包展开。
7. 所有写操作必须经过认证、服务端校验和审计，禁止前端直接拼装数据库状态。
