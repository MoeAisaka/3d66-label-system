# ADR-0043：TPENG 中台 Canonical 事实与资产语义投影边界

## 状态

已接受（上层架构约束；2026-08-11）

关联：ADR-0029（统一标签生产与消费）、ADR-0041（标签机制与模型管理执行合同）、ADR-0042（统一产品载体）

## 背景

ADR-0042 已将“标签体系重构”与“标签实验台”合并为一个产品定位。本 ADR 进一步固化 TPENG
标签实验台作为标签/内容中台通用底座时必须遵守的业务闭环、事实主权、向量责任和发布消费边界。
这些约束用于指导后续 PRD、数据模型和服务拆分，不代表立即扩大 ADR-0041 的冻结实施批次。

## 决策

### 1. 统一定位与业务闭环

- 统一产品名称为 **TPENG 标签实验台（LabelLab）**。它既是“标签体系重构”的产品载体，也是
  标签/内容中台重构的通用底座；“标签体系重构”不再作为并列项目线。
- 统一底座的目标闭环为：

  ```text
  下游字段需求合同 → 素材接入 → 标注路径/任务 → 自动与人工标注
  → 纠偏验收 → 版本发布 → 下游引用/对账 → Badcase 回流
  ```

- 业务类目是底座上的场景扩展，只定义类目合同、路径、提示词、维度、规则、回归门槛和展示差异，
  不复制平台通用能力。

### 2. Canonical 事实主权

- `semantic.*`、`quality.*`、`governance.*` 等资产字段属于中台 Canonical 事实命名空间。人工真值、
  证据、来源、模型/规则版本、审核状态和发布状态必须可追溯，并能定位到资产版本、机制版本和模型版本。
- 搜索索引、知识图谱和向量索引都是可重建的消费投影，不能成为事实主库，也不能反向覆盖 Canonical
  事实。投影必须记录输入版本、生成版本、失效状态和对账结果。
- Query×素材相关性、排序权重、多路召回融合、在线实验参数以及知识图谱内部关系属于下游策略，
  不写入素材 Canonical 事实。

### 3. 向量责任边界

- **标签中台**负责内容资产、图片、文本片段和多模态 Embedding 的生成、版本、失效、重算、回退和质量对账。
- **知识图谱**负责实体、关系、路径和图结构 Embedding；其图内关系不等于素材标签事实。
- **搜索/推荐**负责 Query Embedding、Query×素材相似度、多路召回融合、排序权重和在线实验。
- TPENG 中台产品模块统一称为 **资产语义投影服务**。向量是可版本化的语义投影，不直接定义为标签。

### 4. 发布与消费

- 机制发布轴与标签事实发布轴继续独立：机制启用不自动触发存量重跑，也不自动覆盖历史标签。
- 下游只消费正式发布事实，不读取候选机制、实验结果或人工处理过程。
- 所有索引和投影都必须能够按资产版本、机制版本和模型版本重建，并能与 Canonical 事实做质量对账。

### 5. 本轮处理方式与后续冻结

- 本轮只将约束写入 ADR、PROJECT_STATUS 和能力映射 Gap 清单；不因本同步实现字段注册中心、
  Embedding 生命周期、通用投影注册/重建服务、真实批量重跑 Worker 或生产接入。
- 当前实施范围、非目标、权限、风险、回退、验收和停止条件继续以 ADR-0041 为准，不因本 ADR 改写。
- 当前批次完成后，Gap 清单返回【标签体系】重构会话，由 Owner 冻结下一阶段范围；冻结后仍由
  TPENG 标签实验台会话作为唯一代码写入方实施。

## 当前实现映射结论

当前代码已覆盖素材接入、类目评测/任务、自动与人工结果、纠偏/回流、双发布轴、下游正式标签消费和
基础对账接口；独立下游字段需求合同、Canonical 资产事实命名空间、统一资产版本身份、通用投影注册与
重建、Embedding 生命周期和真实存量重跑执行仍属于后续 Gap。详细证据与边界见
[`docs/discussion/tpeng-platform-capability-map-and-gaps-20260811.md`](../discussion/tpeng-platform-capability-map-and-gaps-20260811.md)。

## 后果

- 后续 PRD 和数据设计必须先区分 Canonical 事实与消费投影，再定义索引、图谱和向量的重建/对账合同。
- 类目扩展可以快速变化，但不能改变平台事实主权或绕过正式发布消费边界。
- 当前实现不因架构约束同步而返工；Gap 进入下一阶段候选池，等待 Owner 单独冻结。

## 不可破坏约束

- 不把搜索、知识图谱或向量索引当作素材事实主库。
- 不把向量直接命名或持久化为标签事实。
- 不把 Query×素材相关性、排序权重或知识图谱内部关系写入素材 Canonical 字段。
- 不让下游读取候选机制、实验结果或人工处理过程。
- 不以本 ADR 为理由扩大当前冻结合同、生产权限或真实模型/批量数据操作。
