# ADR-0007：可选单提示词评测与服务端权威评分

- 状态：Accepted
- 日期：2026-07-20
- 替代：ADR-0002 中“只能使用 A/B 两阶段”的限制

## 背景

系统默认采用 A/B 两阶段以降低 Lite 模型漏字段、同分和虚高风险，但实际运营还存在只有一版完整提示词、没有 A/B 拆分的情况。任务创建必须兼容这种提示词，同时保持历史两阶段任务可追溯。

## 决策

- A/B 两阶段继续作为默认稳定模式。
- 新增单提示词模式，一次调用必须返回范围、分类、画质、素材形态和八个美感维度的完整结构。
- 单提示词结果继续适配为统一的预检与美感结构，最终总分、L1～L5 和等级限制仍由版本化服务端评分引擎计算。
- 任务和结果快照明确显示“单提示词”，不伪装成 A/B 两个版本。
- 人工只能纠正维度分数；人工最终总分和等级由相同服务端评分规则自动重算，不能手工指定。

## 后果

- 单提示词若没有返回完整结构，任务明确失败并提示结构要求。
- 历史 A/B 任务、提示词快照和结果解释能力保持不变。
- 单提示词减少一次模型调用，但其稳定性仍需通过黄金样本和人工抽样验证。

## 不可破坏约束

无论使用单提示词还是 A/B 两阶段，都不得让模型或人工直接指定最终总分和等级，也不得绕过服务端评分、等级上限和审计记录。
