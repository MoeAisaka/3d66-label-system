# ADR-0003：模型与提示词独立版本化并固定组合快照

- 状态：Accepted
- 日期：2026-07-19

## 背景

模型升级会改变对同一提示词的理解，而提示词修改也会改变同一模型的输出。仅记录“当前模型”或“当前提示词”无法解释历史结果。

## 决策

- 模型配置与 A/B 提示词分别管理和版本化。
- 提示词版本不可覆盖：新修改创建新草稿，旧 published/archived 永久保留。
- 每条评测结果固定保存模型 ID、A/B 提示词版本、Rubric、评分引擎和高风险复核版本。
- 更换模型时，模型×A×B 被视为新的候选组合，必须重新验证；不强制先改提示词，回归失败后再创建适配版本。
- 长期应增加一等的发布组合实体，统一锁定模型、A、B、Rubric、Engine 和抽样策略。

## 后果

- 结果比较必须注明组合，不能只写“豆包结果”。
- 相同提示词在新模型上的通过率不能由旧模型结果推断。
- 当前任务/结果快照已经满足追溯，发布组合实体仍是 P0 待办。

## 不可破坏约束

禁止在原记录上替换模型 ID、提示词版本或评分版本来伪装重新运行。
