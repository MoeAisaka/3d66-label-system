# ADR-0008：随拍图与画质受损图片最高 L2

- 状态：Accepted
- 日期：2026-07-21

## 背景

旧评分规则将随拍图最高等级设为 L3，且没有对轻度或中度画质受损执行统一的服务端等级上限。这会让素材形态或技术质量明显不足的图片仅凭美感维度获得过高等级。

## 决策

- A 阶段明确判定 `casual_snapshot.status=yes` 时，最终等级最高为 L2；低置信度结果同时进入人工复核。
- `image_quality.quality_severity` 为 `slight`、`moderate`、`severe` 或 `unusable` 时，最终等级最高为 L2。
- 严重或不可用画质在置信度和证据达到既有阈值时继续执行更严格的 L1 上限。
- 规则由服务端评分引擎强制执行；提示词中的 `decision_rules` 只提供可解释信号，不能绕过服务端限制。
- 评分引擎版本提升为 `engine-v2.5.0`，提示词候选和规则标识提升为 `space_aesthetic_dimensions_v1.4-lite.2` / `space-rubric-v1.4`。

## 后果

- 新评测与人工维度纠正后的自动重算都会应用相同上限。
- 未经人工审核的旧结果可由现有确定性重算流程升级；已审核结果保留原评分引擎快照。
- 多个等级上限同时命中时继续取最低等级。

## 不可破坏约束

不得仅修改模型提示词来实现该规则，也不得允许前端或人工审核绕过服务端 L2/L1 等级上限。
