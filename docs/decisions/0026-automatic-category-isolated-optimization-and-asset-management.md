# ADR-0026：类目隔离的自动优化闭环与素材通道管理

## 状态

已接受，2026-08-01。

## 决策

1. 最终人工纠偏在同一事务内写入对应 `category_key` 的系统黄金集和优化案例队列。
2. 常驻 Worker 自动消费队列；组批键至少包含 `category_key + prompt_version`，不同类目不得共享优化 run、黄金集或回归样本。
3. 一个优化 run 生成的全部候选提示词都必须完成配对回归并汇总后，才进入人工二审；二审前不得自动发布。
4. 类目上传通道在上传时选择，素材可以在没有排队/运行任务时手动切换所属通道；切换、批量删除和包删除全部写审计。
5. 删除使用软删除。素材包删除隐藏活动包并软删除包内素材，包条目、原文件、历史评测、黄金真值和审计继续保留。
6. 生产反馈事件必须显式携带 `category_key`，禁止兼容默认猜测空间图片类目。

## 结果

人工只负责产出纠偏案例、提示词版本二审和维度方案决策；平台级模型凭证、预算和执行器治理仍由管理员一次性维护，不作为每批案例的操作步骤。
