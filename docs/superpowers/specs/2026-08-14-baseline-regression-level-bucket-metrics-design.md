# 基准回归等级与聚合档指标展示设计

## 目标

在基准回归结果主区域补齐当前任务的等级质量指标，同时完整保留现有 L1–L5 五档混淆矩阵和逐等级证据。

## 指标口径

全局等级指标继续直接读取当前回归任务的 `BaselineLevelMetrics`：

- 精确等级准确率：`exact_accuracy`。
- 相邻等级准确率：`adjacent_accuracy`。

在五档数据之上额外增加三个聚合档，不改变原始等级和混淆矩阵：

- 推荐档：L1、L2。
- 常规档：L3、L4。
- 过滤档：L5。

每个聚合档均展示精确率和召回率：

- 精确率 = 真实等级和预测等级均属于该聚合档的样本数 / 所有预测为该聚合档的样本数。
- 召回率 = 真实等级和预测等级均属于该聚合档的样本数 / 所有真实为该聚合档的样本数。

同一聚合档内的等级偏差视为聚合档命中。例如真实 L1、预测 L2：推荐档命中，但精确等级不命中。分母为零时前端展示 `—`，不得展示误导性的 `0%`。

## 架构与数据流

后端现有 `BaselineLevelMetrics.confusion_matrix` 已包含计算所需的完整五档事实。本次不新增 API 字段、不修改数据库、不改变历史任务快照：

1. 基准回归详情接口继续返回现有五档混淆矩阵。
2. 前端纯函数按聚合档定义从混淆矩阵计算 TP、预测总数、真实总数、精确率和召回率。
3. 当前选择的回归任务变化时，主区域随该任务的 `metrics` 自动更新。
4. 五档混淆矩阵继续保留在现有指标证据视图中，不删除、不折叠为三档，也不改变矩阵含义。

## 页面展示

回归结果主区域新增独立的“等级表现”信息组：

- 第一组展示精确等级准确率、相邻等级准确率。
- 第二组展示推荐档、常规档、过滤档；每个聚合档同时展示精确率与召回率。

现有字段准确率、字段召回率、人工门禁、下一步操作和五档矩阵继续保留。聚合档指标是额外信息，不替代任何现有指标或证据入口。

## 边界与异常处理

- 指标只基于当前任务已有的有效等级预测；失败、未完成和无法计分样本沿用后端现有分母规则，不在前端重新解释。
- 前端不得写死示例数字。42%、87%、68.09%、80%、60.87%、70% 仅作为验收示例，实际值必须随任务数据变化。
- 不新增人工配置项，不触发评测、纠偏、重跑或真实模型调用。
- 本次不调整五档等级定义、类目合同、发布门禁或下游消费逻辑。

## 测试与验收

- 为回归页前端合同增加断言，确认全局两个指标和三组聚合指标均存在。
- 保持现有五档矩阵合同测试通过。
- 运行 TypeScript、生产构建、前端合同测试和后端全量测试。
- 在已登录 Edge 中切换不同历史回归任务，确认指标随当前任务变化，且五档矩阵仍可查看。
