# 灵感图调用 B v2 与语义软封顶设计

## 目标

在不改变现役修订 9、历史运行、人工真值、模型和 2,200 张全量门禁的前提下，创建一个未发布的灵感图候选：修复调用 B 的八维等级方向，并让“随手拍”从绝对分数 59 的实现细节变为稳定的 L4 质量上限语义。候选只允许在固定 100 张基准集上验证；未通过门禁不得全量回归、启用或发布。

## 已验证根因

- 运行 20 使用修订 9；运行 23 同时引入调用 B 补强提示词、第五锚和修订 11，不能直接归因。
- 将运行 20 的冻结 A/B 输出离线重放到修订 11 后，精确等级准确率从 47% 到 49%，相邻准确率从 86% 到 91%，L5 召回从 45% 到 80%。阈值/规则是 L5 收益的主要来源。
- 将运行 23 的冻结 A/B 输出离线重放回修订 9 后，精确等级准确率为 41.84%，低于运行 20 的 47%。现有调用 B 补强和第五锚没有提供可证明的五档净收益。
- 运行 23 的候选提示词没有声明 `grade` 方向；多张高质量图输出八维全 1，过滤图输出全 5，说明八维语义可逆且不能稳定解释分数。
- 旧规则的 `casual_snapshot_soft_cap=59` 在修订 9 对应 L4，在修订 11 因 L5 分数带为 0–59 而变成 L5。这是 L4 被误压到 L5 的确定性根因。

## 方案选择

比较过三种方案：

1. 仅把 59 改成 60：改动小，但仍绑定绝对阈值，下一次调阈值会重现同类错误；不采用。
2. 只改调用 B 提示词：能修正八维语义，但保留 L4 被硬压 L5 的规则缺陷；不采用。
3. 调用 B 合同修复加语义软封顶：调用 B 明确维度方向并退出红线职责；随手拍用 `cap_to_level=L4` 计算动态分数上限，另以两项低维质量信号作为升级 L5 的窄门；采用。

## 冻结设计

### 调用 B v2

- 新建草稿提示词版本，不覆盖历史提示词。
- 明确 `grade=5` 表示该维度优秀、`grade=1` 表示严重失效；总分与此方向一致。
- 调用 B 只判断第六张待评图的美感基础、八维证据与不足；红线、内容范围、赛道、最终等级和硬拒绝仍完全由调用 A 与 V3 负责。
- 删除“先做红线检查”“红线时不高于 49 分”等指令，避免与调用 A/V3 重复且促成分数两极化。
- 保留 L1–L5 五锚与 90/80/76/60/0 美感分数带；普通、清晰但无多维强证据的图默认停在 L3/L4，而不是自动进入 L2。
- `overall_evidence` 和每维 `shortcomings` 继续为非空/可审计合同；同一等级可以出现，但必须各自说明可见理由。

### V3 语义软封顶

候选合同将 `casual_snapshot_soft_cap` 改为下列版本化形状：

```json
{
  "key": "casual_snapshot_soft_cap",
  "signal": "production_fields.reason",
  "match_any": ["是随手拍"],
  "cap_to_level": "L4",
  "filter_escalation": {
    "cap_to_level": "L5",
    "dimensions_at_most": {
      "presentation_integrity": 2,
      "inspiration_reference": 2
    }
  }
}
```

- `cap_to_level=L4` 的实际分数上限从候选冻结 `score_thresholds` 推导：上一个更好档 L3 的下限减 1。对 90/80/76/60/0 即为 75，而不是旧的 59。
- 只有命中“是随手拍”且呈现完整性、灵感参考价值均不高于 2 分时，才额外压入 L5；该规则必须记录命中证据。
- 调用 A 红线、A 级硬伤仍先于此规则，保持既有 L5 路径。新的窄门不覆盖或放松它们。
- 旧合同的 `cap_to` 保持原样回放；只有新候选使用 `cap_to_level`。引擎按合同形状选择版本，现役运行仍字节级重放。

## 数据流与失败处理

调用 B 输出先经过现有严格 JSON 校验，再进入 V3。V3 先执行红线、赛道和硬伤，再执行语义软封顶。候选合同形状非法、等级不存在、阈值不连续或升级维度不完整时关闭失败；不得退回旧的 59 分规则，也不得伪造预测。

## 验收与停止条件

- 单元测试必须覆盖：旧 59 分合同不变；新 L4 语义上限为 75；低维双信号才进入 L5；单一低维或非随手拍不升级；红线和 A 级硬伤优先。
- 100 张门禁必须单独报告有效预测数和技术失败；技术失败不伪装成业务误判。
- 主口径为五档精确率、相邻准确率、每档精确率/召回率，重点 L1 精确率和 L5 召回率；同时报告推荐/常规/过滤三档准召。
- 与运行 20 及运行 23 的配对差异一并报告。若五档或三档门禁仍不通过，停止，不启动 2,200 张全量回归。
