# 下游字段与表投影合同 v1（宣讲与研发对齐稿）

## 1. 合同目的

本合同定义 TPENG 标签实验台向下游数据库表供给正式标签事实的最小边界。下游实际消费形态为一个统一大维表和数个职责小表；本合同不授权真实数据库写入，真实库、账号、权限、批次和回退需另行冻结。

## 2. 事实与投影边界

### Canonical 事实

- `semantic.*`：资产语义字段；
- `quality.*`：字段级质量、五档矩阵、失败样本和对账；
- `governance.*`：来源、资产版本、机制/模型/规则版本、人工真值、审核和发布状态。

### 消费投影

- 统一大维表；
- 搜索标签小表；
- 质量过滤小表；
- 治理来源/版本小表；
- 类目专用字段小表；
- 变更事件或回流队列表。

搜索 Query×素材相关性、排序权重、多路召回融合和知识图谱内部关系不进入素材 Canonical 事实。

## 3. 表职责建议

| 表类型 | 主要职责 | 允许读取 | 不允许承载 |
|---|---|---|---|
| 统一大维表 | 稳定宽字段、详情、基础筛选、通用读取 | 正式发布的 semantic/quality/governance 字段 | 候选机制、人工过程、Query 相关性、排序权重 |
| 搜索标签小表 | 面向搜索/筛选的正式标签投影 | 已发布标签值、字段版本、失效状态 | 搜索排序实验参数、Query×素材分数 |
| 质量过滤小表 | 质量分、风险项、过滤档和审核状态投影 | 正式 quality/governance 字段 | 未发布候选、原始模型响应 |
| 治理来源小表 | 来源、资产版本、机制/模型/规则版本和发布状态 | 正式 provenance | 外部系统凭据、候选过程 |
| 类目专用小表 | 类目扩展字段和专用视图读取 | 已发布 `category.*` 字段 | 第二套平台事实、未审计派生值 |
| 变更/回流小表 | 正式变更事件、对账差异、Badcase 入口 | 已发布变更和差异证据 | 直接修改 Canonical 事实的指令 |

## 4. 最小字段合同

| 字段 | 说明 | 来源 |
|---|---|---|
| `content_key` | 稳定资产业务主键 | Canonical 资产身份 |
| `asset_version_id` | 不可变素材版本 | 资产版本合同 |
| `label_fact_version` | 正式标签事实版本 | 标签事实发布轴 |
| `mechanism_release_id` | 机制正式发布版本 | 机制发布轴 |
| `model_version` | 产生事实的模型版本 | 模型注册中心 |
| `semantic.*` | 平台语义字段 | 平台字段合同 |
| `quality.*` | 字段质量、五档矩阵或质量状态 | 质量事实 |
| `governance.*` | 来源、审核、发布和失效状态 | 治理事实 |
| `projection_batch_id` | 投影批次与重试边界 | Projection Manifest |
| `idempotency_key` | 单写者幂等键 | 投影合同 |
| `generated_at` / `invalidated_at` | 生成和失效时间 | 发布/投影运行时 |
| `payload_hash` | 确定性对账哈希 | 投影 Manifest |

## 5. 投影与对账

每次投影必须生成 Manifest，至少包含：

- 输入资产版本范围；
- 标签事实版本；
- 机制版本和模型版本；
- 目标表和目标批次；
- 幂等键和单写者信息；
- 行数、缺失字段、版本匹配和 payload hash；
- 失败原因、重试次数、检查点和回退版本。

投影失败只记录差异、重试或补偿，不修改 Canonical 事实。发现版本漂移、数量不一致、缺失超阈值或哈希不一致时停止发布并回退到最近正式事实。

## 6. Badcase 回流

下游可以回流：

- `content_key`、资产版本和投影批次；
- 命中的字段和当前正式标签；
- 消费场景、错误类型、证据和复现信息；
- 下游 Owner、时间和优先级。

Badcase 进入中台纠偏队列后，由系统自动汇总样本、调用调优模型生成候选机制并执行自动回归；人工仍分别决定候选机制是否启用、标签事实是否发布。

## 7. 暂不授权

- 不允许下游表成为事实主库；
- 不允许下游表反向覆盖 Canonical；
- 不允许读取候选机制、实验结果或人工处理中间态；
- 不允许使用未经签认的字段词表、Owner、SLA 或生产权限；
- 不允许在本合同基础上直接执行真实数据库 DML。
