# 3D/SU 黄金集计划 v1

## 用途

本计划只定义 3D/SU 首批真实闭环的黄金/挑战样本门槛，不导入真实素材，不修改现有 SampleSet，也不启动回归。黄金集用于人工真值、机制候选回归、字段级 Precision/Recall、L1-L5 矩阵和失败样本复盘。

## 数量与覆盖

最低锁定样本数为 100。一个样本可以同时命中多个分层，但签认时必须提供覆盖矩阵，且至少满足：

| 分层 | 最低覆盖 | 说明 |
| --- | ---: | --- |
| 3D / SU | 各 30 | 其余可按真实流量补齐，不能只覆盖一种格式 |
| whole / single | 各 30 | whole 与 single 规则必须分别取样 |
| 空间建筑 / 软装家具 / 功能性模型 | 各 20 | 三条评测赛道都必须有可判样本 |
| L1 / L2 / L3 / L4 / L5 | 各 10 | 保留完整五档回归与边界样本 |
| 语义 hardcase | 至少 20 | 含多义、不可判、词表外、not_applicable、not_detected、needs_review |
| 挑战样本 | 至少 20 | 含白边、低质量预览、遮挡、跨风格、相邻等级和冲突证据 |

真实流量分布可作为第二套报告，但不能替代上述挑战覆盖。若一个样本跨层计数，manifest 必须保留其全部 strata，避免重复导出时被误认为独立素材。

## 真值规范

- 每条样本绑定 `content_key`、素材版本、来源身份签认版本和内容哈希；
- 每个字段记录值、证据、空值语义、词表版本、标注人、复审人和时间；
- 美感等级保留 L1-L5 真值、证据与争议说明；
- 关键字段和等级至少由两名人工独立判断，冲突由指定 Reviewer 裁决；
- 未签认身份、原图不可复核或证据不足的样本只能进入 challenge/pending，不得充当锁定真值。

锁定后只允许创建新的 `SampleTruthRevision` 或新 SampleSet。禁止 UPDATE 锁定 revision，禁止用当前真值回算并覆盖历史运行快照。导出只包含已授权的字段、真值和证据引用，不包含候选机制、原始模型响应或凭据。

## 质量门槛

字段级默认门槛为 Precision ≥ 0.80、Recall ≥ 0.70；同时输出宏/微平均、字段混淆、失败样本和分层差异。美感评测保留 L1-L5 五档矩阵、单档 Precision/Recall、精确等级准确率、相邻等级准确率，以及推荐档 L1/L2、常规档 L3/L4、过滤档 L5 的附加指标。

任何门槛下降、样本剔除、真值修改或 strata 缩减均需新 revision 和 Owner 签认，不能通过修改历史结果获得通过。

## 签认与停止条件

Data Owner 签身份与数据窗口，Product/Label Owner 签字段和样本覆盖，Reviewer Owner 签真值过程，Algorithm Owner 签回归口径，Consumer Owner 签下游验收字段。样本不足 100、任一核心分层缺失、真值证据无法复核、身份冲突或版本漂移时停止进入真实回归。
