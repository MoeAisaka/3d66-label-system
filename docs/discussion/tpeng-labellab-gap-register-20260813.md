# TPENG 标签实验台下一阶段 Gap 清单（2026-08-13）

## 用途

本清单是当前冻结批次完成后返回【标签体系】重构会话的范围冻结输入，不是实施授权。Owner 需要逐项冻结
目标、范围、权限、数据源、回退、验收和停止条件；冻结后仍由 TPENG 标签实验台会话作为唯一代码写入方。

## 90 天证据链建议

1. 正式标签生产：真实字段需求合同驱动一个类目增量素材完成评测与人工纠偏。
2. 双轴发布：候选机制人工启用，正式标签事实另行人工发布，全程可追溯。
3. 数据库投影：正式事实生成统一大维表与目标小表，完成版本、行数、缺失和哈希对账。
4. 首个消费场景：优先选择 3D 搜索，只消费正式投影，不读取候选和人工过程。
5. 效果评估：以字段准确率、召回率为底座指标，结合搜索会话有效浏览等下游指标验证影响。
6. Badcase 回流：下游错例回到纠偏样本，触发 AI 候选与自动回归，最终仍由人工决定是否启用。

## 停止条件

- 发现真实数据库或外部系统被未授权写入；
- 候选机制、实验结果或人工过程被下游读取；
- 投影反向覆盖 Canonical 事实；
- 候选被自动启用、标签事实被自动发布或机制启用自动覆盖存量；
- 无法证明资产、标签、机制、模型版本与投影行之间的对账关系。
