# 类目评测等级规则配置 · 新手教程（人话版）

> 这份教程给「第一次进这个配置页、看不懂那些字段」的人。读完你能自己配一个类目怎么评分。
> 位置：高级设置 → 类目评测等级规则配置。

---

## 0. 先搞懂这个页面到底在配什么（一句话）

**你在教系统「怎么给一张图打分、判等级」。** 一张图进来，系统按你配的规则走四步：

```
① 红线检查（有硬伤直接淘汰）
   ↓ 没被淘汰
② 赛道分类（这张图算哪一类，决定满分是多少）
   ↓
③ 维度打分（从满分里按各维度表现扣分）
   ↓
④ 收尾封顶（媒介降权 + 高分有硬伤压分 + 赛道上限）
   ↓
最终：一个 0-100 的分 + 一个 L1~L5 等级
```

**记住两个方向，别搞反：**
- **分数**：0-100，**越高越好**（下游直接用这个数）。
- **等级 L1~L5**：**L1 最好、L5 最差**（跟分数反着记：高分→L1，废图→L5）。

---

## 1. 四大配置块，逐个说人话

### 块一：红线规则（`红线`）——"一票否决"清单
**作用**：命中任意一条红线，这张图**直接判死**（锁定低分 ≤49、等级 L5），后面维度分都不用算了。

每条红线你能配：
| 字段 | 人话解释 | 例子 |
|---|---|---|
| `match_any` | 命中关键词/信号，出现任意一个就算命中 | `["是截图","有二维码"]` |
| `exemptions` | 豁免情况，就算命中了但符合这些也放过 | `["角落极小二维码"]` |
| `hit_level` | 命中后判什么等级 | `L5`（最差档） |
| `hit_score_cap` | 命中后分数最高不超过多少 | `49` |
| 启用/关闭开关 | 这条红线要不要生效 | 开 / 关 |

**新手操作**：想加一条"模糊图直接淘汰"？点新增红线 → `match_any` 填"模糊发灰" → `hit_level` 选 L5 → 保存。想临时停用某条？把开关关掉，不用删。

---

### 块二：赛道（子类目）——决定"满分是多少"
**作用**：不同类型的图评分标准不同。系统先判这张图属于哪个赛道，赛道决定了它的**分数怎么起算**。

每个赛道你能配：
| 字段 | 人话解释 | 灵感图的例子 |
|---|---|---|
| `base_score` | 基础分（起步就给的分） | 一类 40 |
| `dimension_max` | 维度能加的满分池（维度全拿满能得这么多） | 一类 60 |
| `track_cap` | 这个赛道的分数天花板（再高也封到这） | 一类 100 |
| 默认赛道 | 判不出类时兜底归到哪个赛道 | 三类 |

**怎么理解**：`base_score + dimension_max = 满分`。灵感图一类 = 40+60 = 100 封顶；二类 = 20+60 = 80 封顶（所以二类再好也上不了 80+）；三类 = 40+30 = 70。**你想让某类图"最高只能给 80 分"，就把它的 `track_cap` 设 80。**

---

### 块三：维度组（`维度`）——"从满分里按表现扣分"
**作用**：这是打分的核心。每个赛道有一组维度（比如"视觉结构""色彩美学"），调用B（AI）给每个维度打 **1-5 分**（1 最差、5 最好），系统按分扣钱。

每个维度你能配：
| 字段 | 人话解释 |
|---|---|
| 维度 `key` / 名称 | 这个维度叫什么（如 visual_structure 视觉结构） |
| `weight` | 权重（这个维度占维度满分池的比例，一组权重加起来=1） |
| `grade_points` | 1-5 分各对应多少档位（一般用默认线性即可） |

**怎么理解 weight**：假设赛道维度池 `dimension_max=60`，某维度 `weight=0.25`，那它最多影响 `60×0.25=15` 分。AI 给它打 5 分 = 不扣；打 1 分 = 这 15 分全扣光；打 3 分 = 扣一半。

**维度可以自由增删、也可以留空**：
- 想加维度：点新增，填 key + 名称 + 权重，**记得让一组权重加起来=1**（系统会校验）。
- 想删维度：直接删。
- **整组留空**：这个赛道就变成"只靠提示词评，不做维度扣分"。

> 空间图、材质图、PDF 文本已复制灵感图的人工校准等级规则作为初版并全部激活。请在各自类目中修改，系统禁止跨类目引用 category_key 不匹配的提示词。

---

### 块四：收尾规则 + 状态

**媒介降权（`media_type_penalty`）**：同样质量下，不同来源的图扣不同分。灵感图：实拍图不扣、效果图 -5、AI 图 -15。想调就改对应数字。

**高分压分（`high_score_veto`）**：分数 ≥ 某阈值（如 80）**且**这张图有硬伤时，强制压到某个上限（如 79）。防止"有明显毛病的图混进高分段"。

**分类置信度（`min_confidence`）**：AI 判类目时低于这个信心值，就归到兜底赛道。一般 0.6，不用动。

**状态（`status`）——最重要，决定这套配置生不生效：**
| 状态 | 含义 | 后果 |
|---|---|---|
| `draft`（草稿） | 编辑中，**不生效** | 新任务 fail-closed，不能回退 v1 |
| `active`（激活） | **正式生效** | 该类目的图**立刻**用这套等级规则评分 |
| `retired`（退役） | 停用 | 新任务 fail-closed，需先激活可用等级规则 |

> 🚨 **激活即生效、影响线上评分**。改配置时用草稿慢慢调，**确认没问题了再激活**。激活后建议先拿几张已知好/坏的图试评，看分数符不符合预期。

## 2. 三个最常见的操作，照着做

**A. 我要新增一个类目的评分规则**
1. 新建 config → 填 `category_key`（类目英文名）+ 显示名
2. 配红线（块一）→ 配赛道基底/满分/封顶（块二）→ 每赛道配维度+权重（块三）→ 配媒介降权/压分（块四）
3. 先存**草稿**，点「校验」看有没有报错
4. 拿测试图试评 → 满意 → 改 `status=active` 激活

**B. 我要改现有类目的维度（比如加一个"环保材料"维度）**
1. 打开该 config → 维度组里新增维度 → 填 key/名称/权重
2. **把这组权重重新分配，让总和=1**（否则校验不过）
3. 存草稿 → 校验 → 试评 → 激活

**C. 我觉得某类图分数普遍偏高/偏低**
- 偏高：调低相关维度的宽松度（或加红线/压分规则）
- 偏低：检查是不是媒介降权太狠、或维度权重压太重
- **改完一定先草稿试评再激活**

---

## 3. 记住这几条就不会配错
1. **分数越高越好；等级 L1 最好 L5 最差**（别搞反）。
2. **一组维度的权重必须加起来 = 1**，否则存不了。
3. **草稿不生效、激活才生效**——线上评分只看 active 的配置。
4. **红线是一票否决**，命中直接 L5，谨慎加。
5. **改配置不用改代码**，全在这个页面点，改完试评再激活。
6. 拿不准就先建草稿试评，**别直接在 active 上乱改**。
