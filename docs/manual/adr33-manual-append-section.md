## 24. 类目自定义评测底座（ADR-0033，预览阶段）

### 24.1 这是什么
把评测从"只看美感分"升级为按类目高度自定义的确定性流水线：

**红线筛查（命中直接判 L5 淘汰）→ 分类器（类目→子类目）→ 子类目提示词 A/B → 维度评测（子类目共性维度 + 特有维度）→ 产出（等级 + 分数 + 固定字段）**

- 红线规则、共性维度、特有维度都可自由增删和开关，数量不限、都可为 0。
- 等级方向以本手册规则为准：**L5 = 最差（废图/淘汰档），L1 = 最优**。
- 完整流水线（增量未定性素材）与存量回归（已定性素材）走同一套评测引擎，能力完全一致，只是素材来源不同。

### 24.2 调用 A / 调用 B / 维度 各管什么（避免填错位置）
- **调用 A（预检）**：只识别事实——分类、媒介类型（实景/效果图/AI/其它）、红线信号（是截图/大面积文字/二维码/随手拍等）、生产字段。不出维度分、不出最终等级。
- **调用 B（维度评价）**：只按子类目对每个维度打 1-5 级并给证据。不出总分、不做降权。
- **维度层（系统自动）**：把 A、B 的结果按固定顺序算成分数和等级（红线→赛道→维度扣分→媒介降权→高分压分→赛道封顶→等级映射）。红线和媒介降权是系统确定性规则，不要写进调用 B 的提示词。

### 24.3 在哪里看 / 怎么试
- 入口：高级设置 →「类目评测底座预览」（`/workflow/optimization/category-evaluation-preview`）。
- 左侧只读展示当前灵感图类目的红线规则、三个子类目赛道（分数基底/维度满分/上限：一类 40+60≤100、二类 20+60≤80、三类 40+30≤70）、媒介降权（实拍 0 / 效果图 -5 / AI -15）、高分一票压分（≥80 且有硬伤→封顶 79）。
- 右侧「Dry-run 试算」：填入一张图的分类、媒介、置信度、红线信号，以及模拟的共性/特有维度 grade，点运行即可看到完整链路每一步的分数变化、最终等级和封顶原因。**该页只试算、不写库、不影响线上评测。**

### 24.4 当前阶段与边界
- 本底座目前处于**预览/试算阶段**：可完整跑通并验证配置，但**尚未替代线上正式评分**。
- 尚未开放：worker 正式接线（用新引擎替代线上算分）、等级方向的全局迁移、类目配置的在线可视化编辑（红线/子类目/维度组增删）。这三项因涉及生产评分与已发布标签，将由管理员在单独窗口带回归验证后上线。
