## V1.3 Split.3 画质与摄影类型校准规则

本节优先级高于前文和 Split.2。业务目标不是判断文件能否打开，而是判断当前图片是否达到可用于设计素材库的呈现质量。能够看清主体，不等于画质正常；构图端正，不等于专业摄影。

### 1. 专业摄影硬约束

`professional_photography.status=yes`必须同时满足：

1. `real_photo.status=yes`；
2. `rendering.status=no`且`ai_generated.status=no`；
3. `image_quality.quality_severity=normal`且`capture_quality=good`；
4. 至少四条互不重复的出版级摄影证据，分别覆盖机位与透视、边缘与裁切、光线与动态范围、主体组织或后期控制；
5. 不存在明显噪点、过曝、暗部堵塞、灰雾、色偏、低微反差、随意反射、无关遮挡、异常裁切或大面积无意义留白。

只要`rendering=yes`或`ai_generated=yes`，`professional_photography`必须为`no`。效果图、AI图和商品合成图可以“呈现精致”，但它们不是摄影。

只要画质为`slight|moderate|severe|unusable|uncertain`，默认不得判为专业摄影。若图片只是清晰、对称、主体居中或透视基本正确，应判为普通现场记录或随拍，而不是专业摄影。

在 3D66 当前业务口径中，`scene_scope.type=partial_space`属于局部记录：`professional_photography`必须为`no`；若为实景图，应优先标记`documentary_record=yes`。局部空间因为缺少完整呈现，`quality_severity`至少为`slight`。

### 2. “画质正常”必须全部通过

`quality_severity=normal`必须同时满足以下条件，缺一不可：

1. 主体边缘与纹理清楚，没有可见软焦、运动模糊、过度锐化或放大痕迹；
2. 高光没有泛白丢失，暗部没有堵塞，整体不发灰、不浑浊，局部照明不过度刺眼；
3. 没有可见噪点、胶片颗粒、压缩块、像素化、色带或重复保存损伤；
4. 色彩和白平衡可信，没有明显偏色、褪色、脏色或不自然饱和；
5. 当前文件没有大面积无意义白边、品牌水印、扫描翻拍痕迹或影响判断的反射与遮挡；
6. 实景图的材质和空间层次可可靠观察；效果图的建模、材质、阴影、透视和尺度没有明显失真。

“清晰度足够”“主体可识别”“不影响分类”“属于有意风格”都不能单独支持`normal`。

出现品牌水印、大面积装饰边框或可见未完工区域时，`quality_severity`至少为`slight`，不得输出`normal`。

### 3. 严重度执行规则

- 出现一项可见但不影响主体判断的问题，至少为`slight`；
- 出现两项及以上问题，或单项问题覆盖主体/大面积画面，至少为`moderate`；
- 主体纹理、边缘、材质或空间关系大面积丢失，为`severe`；
- 无法可靠识别或比较主体，为`unusable`；
- 不能确认问题是否为有意处理时输出`uncertain`并要求复核，不得回退为`normal`。

胶片感、复古色调和风格化处理可以写入`tonal_intent`，但只要颗粒、偏色、低反差或高光溢出降低了素材库使用质量，`quality_severity`仍必须至少为`slight`。

以下现象必须写入`issues`和`evidence`：噪点/颗粒、软焦、过曝高光、暗部堵塞、色偏、灰雾、低微反差、压缩、像素化、过度锐化、大面积白边、水印、反射干扰、渲染材质塑料感、阴影或透视不一致。

### 4. 典型误判纠正

- 复古家具场景即使整洁、配色完整，若疑似效果图或AI图，也不得标为专业摄影；
- 商品柜体效果图带品牌水印或大面积白边时，画质不得为`normal`，且专业摄影必须为`no`；
- 扶梯等公共空间图片存在明显颗粒、偏色、眩光或曝光漂移时，至少为`slight`，不得用“胶片风格”豁免；
- 普通室内局部图即使分辨率较高，若只是正面记录、边缘裁切生硬、反射或高光失控，也不得仅凭清晰度判为专业摄影；
- 卫浴等狭小空间出现灯具高光溢出、镜面干扰、门框遮挡或动态范围失控时，至少为`slight`。

### 5. 输出前强制自检

1. 若`professional_photography=yes`，是否满足真实照片、正常画质和四类出版级证据？
2. 若`quality_severity=normal`，是否逐项排除了六类问题，而不是只写“清晰、细节完整”？
3. 是否把风格化当成了噪点、偏色或曝光问题的豁免理由？
4. 是否把效果图、AI图或商品合成图误写成专业摄影？

任一项不满足，必须修正 JSON 后再输出。
