## V1.3 Split.3 八维差异化评分规则

本节优先级高于前文和 Split.2。3级是量表中点，不是八个维度的默认答案。必须先逐维观察，再独立给分；禁止因为最终等级预计为 L3，就把八个维度全部写成3。

### 1. 独立评分顺序

对每个维度依次执行：

1. 只列该维度的可见优势；
2. 只列该维度的可见缺陷；
3. 判断缺陷是否覆盖主体、是否影响素材使用；
4. 按该维度证据独立给1至5级；
5. 完成八维后再计算整体，不得先决定总等级再反推维度。

不得复制同一句证据到多个维度，也不得用“整体协调、画面清晰、主体明确”支持多个相同等级。

### 2. 缺陷必须映射到对应低分

- 普通站立记录视角、边缘失控、无关元素、主体竞争：`composition_viewpoint`最高2或3；
- 直射硬光、眩光、高光溢出、暗部堵塞、灰雾、缺少塑造：`lighting_atmosphere`最高2或3；
- 材质廉价、塑料感、色偏、脏色、组合普通：`color_material`最高2或3；
- 家具拥挤、尺度失衡、布局模板化、动线受阻：`spatial_design_furnishing`最高2或3；
- 焦点不清、信息拥挤、前中后层次弱：`visual_hierarchy`最高2或3；
- 未完工、未收口、破损、杂物、水印、渲染细节错误：`detail_completion`最高2；
- 明显年代化、常见模板、缺少可迁移方法：`inspiration_reference`最高2或3；
- 局部展示、严重裁切、大面积白边、反射遮挡、曝光或画质问题：`presentation_integrity`最高2或3。

出现明确的“未完工”时，`detail_completion`不得高于2；未完工区域进入主体或前景时，`presentation_integrity`不得高于2。现场记录或随拍若存在明显拍摄缺陷，构图、光影或呈现完整性中至少一个必须低于3。

### 3. 防止中间分坍缩

八个维度全部相同视为无效初稿，无论全部为2、3、4还是5，都必须重新逐维评分。

六个及以上维度相同时，必须检查是否存在：

- 至少一个明显短板维度，应比主档低一级；
- 至少一个相对优势维度，可在证据充分时比主档高一级；
- 被遗漏的画质、裁切、未完工、趋势或局部呈现问题。

最终 JSON 至少包含两个不同的维度等级。只有在八个维度确实表现完全等质且每个维度都有独立证据时才允许同分；本系统不接受这种例外，必须设置`needs_review=true`并重新输出差异化结果。

### 4. 常见图片的合理分布

- 普通但可用的现场记录：通常由2级和3级组成，不应八维全3；
- 有一两项专业优势、同时存在普通项的素材：可以出现3级和4级，但4级必须逐维满足证据门槛；
- 明显未完工或呈现受损的图片：完成度、呈现完整性通常为1或2，其他维度可独立为2或3；
- 效果图或AI图：摄影相关优势不得抬高构图、光影和呈现等级，渲染缺陷要落到对应维度；
- 画质为`moderate|severe|unusable`时，`presentation_integrity`不得高于2。

这些是校准方向，不是固定配额。等级差异必须由图中证据产生。

### 5. 输出前强制自检

1. 八维是否全部相同？若是，重新评分；
2. 是否有六个及以上维度相同且证据高度重复？若是，重新评分；
3. 每个缺陷是否真实降低了对应维度，而不是只写进`defects`？
4. 是否把最终 L3 误解成八维都必须为3？
5. 是否至少形成两个有证据支持的等级档位？

任一项不满足，必须修正 JSON 后再输出。
